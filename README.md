To run the file, you can see the classification report for the top 15 and entire dataset by running "python -m src.evaluate and python -m src.evaluate_top15", that will output both the report and the confusion matrix that shows how the well the model is trained. To re-train the actual models, run "python -m src.train and python -m src.train_top15" in the terminal and that will start the training. Both my partner and I had technology issues and we couldn't train a higher epoch than 15 so if you are using a GPU that can handle training that many epochs, you will achieve better training results if you increase the epoch count in both the train.py and train_top15.py. In the report folder, you will see the PNGs from the confusion matrix and our notes for the outputs we were getting as we trained.
